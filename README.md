# Hi, I'm Thiago de Castro Valverde 👋

🎓 Computer Engineering student at the **University of São Paulo (EESC/ICMC)**  

My work sits at the intersection of **software engineering, robotics, and digital accessibility research**.

Currently, I am involved in two main areas:

## 🤖 Robotics Software
Member of **Warthog Robotics**, contributing to the development of software for autonomous robots in the **RoboCup Small Size League (SSL)**.

Main areas of work:
- Robot **navigation and motion control algorithms**
- Development of autonomous behaviors using **Behavior Trees**
- **High-performance C/C++** software for real-time robotic systems
- Development in **Linux environments**

## 🔬 Research (HCI & Accessibility)
Undergraduate researcher (**PIBIC/CNPq**) at the **University of São Paulo**, working on the **qualitative evaluation of a software architecture designed for learning object assimilation**.

The architecture has been applied to a tool aimed at **improving accessibility in educational content in Brazilian Sign Language (Libras)** using **Automatic Speech Recognition (ASR)**.

Research topics include:
- **Human-Computer Interaction (HCI)**
- **Qualitative evaluation of software systems based on Grounded Theory**
- **Digital accessibility**
- **Content analysis methods** (open, axial, and thematic coding)
